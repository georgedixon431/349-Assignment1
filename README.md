# 349-Assignment1

COMPX349 Assignment 1 - George Dixon 1645268

Build:
make

Run:
./assignment1

Controls:
Enter any letter except q to display the current linked list.
Enter q to exit.

Files:
main.c      - Creates threads, handles user input and prints the list.
input.c     - Reads players.csv and adds players to the linked list.
sort.c      - Periodically performs one bubble-sort pass on the linked list.
criclist.c  - Creates cricketer records from input data.
players.csv - Input player data.
Makefile    - Builds the program.
